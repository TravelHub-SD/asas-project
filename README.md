# مُدَرِّسة خصوصية — موقع نخبة من المعلمين والمعلمات المتميّزين

موقع تسويقي مبني على SEO لنخبة من المعلمين والمعلمات المتميّزين في **جدة** و**الرياض**.
الفكرة الأساسية: **صفحة مستقلة لكل تقاطع (مدينة × مادة)**، كل صفحة تستهدف عبارة بحث واحدة
وتنتهي بتوجيه الزائر إلى **واتساب أو مكالمة**.

لا حجز أونلاين · لا أسعار · لا تسجيل دخول.

الخلفية الكاملة والقرارات في [`docs/asas-context.md`](docs/asas-context.md)،
ومواصفة التنفيذ في [`docs/asas-spec.md`](docs/asas-spec.md).

---

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بناء ثابت لكل الصفحات
npm run typecheck
npm run og       # إعادة توليد صورة OG والأيقونة (بعد build)
```

## المكدّس

Next.js 14 (App Router) · TypeScript · Tailwind CSS · صفحات ثابتة بالكامل (SSG) · نشر على Vercel.
الموقع عربي أولًا: `<html lang="ar" dir="rtl">` وخط Tajawal عبر `next/font`.

## ما الذي يُعدَّل ومن أين

| ما تريد تغييره | المكان |
|---|---|
| اسم البراند · الرقم · الواتساب | `lib/config.ts` — مكان واحد فقط |
| الدومين النهائي | `NEXT_PUBLIC_SITE_URL` أو `SITE_URL` في `lib/config.ts` |
| المدن · المناطق · الأحياء · المواد · المحتوى | `data/catalog.ts` — المصدر الوحيد للحقيقة |
| ترتيب عرض المواد | ترتيب مصفوفة `SUBJECTS` نفسها في `data/catalog.ts` |
| المواد ذات الأولوية | `PRIORITY_SUBJECT_SLUGS` في `data/catalog.ts` |
| صورة OG والأيقونة | `scripts/generate-og.mjs` ثم `npm run og` |
| لوجو الاسم (مسارات SVG) | `scripts/generate-wordmark.py` ثم `npm run wordmark` |

> **اسم البراند مبدئي (placeholder).** لم تعتمده العميلة نهائيًا بعد،
> ولهذا هو `config` يُغيَّر من ملف واحد وينعكس على الموقع كله وعلى صورة OG.

### الدومين

`SITE_URL` تُستخدم في `canonical` و`og:url` و`sitemap.xml` و`robots.txt`،
وتُستنتج بهذا الترتيب (`lib/config.ts`):

1. `NEXT_PUBLIC_SITE_URL` — الدومين النهائي بعد شرائه، يتجاوز كل ما بعده
2. `VERCEL_PROJECT_PRODUCTION_URL` — دومين المشروع الإنتاجي على Vercel (ثابت عبر النشرات)
3. `VERCEL_URL` — رابط النشرة الواحدة (احتياطي)
4. `https://asas.sa` — احتياطي محلي للتطوير فقط

بهذا يكون النشر على Vercel قبل شراء الدومين **صحيحًا تلقائيًا**: كل canonical
يشير إلى دومين المشروع الفعلي لا إلى دومين غير موجود.

بعد شراء الدومين وربطه، اضبط في Vercel:

```
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

> ⚠️ **لا ترفع `sitemap.xml` إلى Google Search Console قبل ربط الدومين النهائي.**
> لو فهرس قوقل نسخة `.vercel.app` ستحتاج لاحقًا إلى تحويلات 301 وتنظيف فهرسة
> بدل بداية نظيفة على الدومين الصحيح.

## بنية الروابط

```
/                              الصفحة الرئيسية
/contact                       تواصل معنا
/[city]                        صفحة المدينة   → /jeddah · /riyadh
/[city]/[subject]              صفحة المادة    → /jeddah/qudrat
/[city]/[region]               صفحة المنطقة   → /jeddah/north · central · south
/[city]/[district]             صفحة الحي      → /jeddah/murwah
/[city]/[district]/[subject]   حيّ × مادة أولوية → /jeddah/murwah/qudrat
/sitemap.xml · /robots.txt     تتولّد من الكتالوج
```

المقطع الثاني قد يكون **مادة** أو **منطقة** أو **حيًا** — يُحسم النوع من `data/catalog.ts`
داخل `app/[city]/[slug]/page.tsx`. الأسماء الثلاثة لا تتقاطع.

**قاعدة توليد صفحات (حيّ × مادة):** تُبنى فقط للأحياء المميّزة (`featured: true`)
مع المواد الأولوية الثلاث في `PRIORITY_SUBJECT_SLUGS`. لا نولّد صفحة لكل حي مع كل مادة
لأن ذلك ينتج صفحات رقيقة متشابهة يعاقبها قوقل.

المناطق لها حقل `published`: مناطق **جدة** منشورة، ومناطق **الرياض** موجودة
في البيانات بـ `false` وتُفتح بتغيير القيمة وإضافة أحيائها.

## ما يوجد في كل صفحة هبوط

- `<h1>` فريد يحتوي عبارة الاستهداف: **«معلمة [مادة] خصوصية في [مدينة/حي]»**
- `<title>` ووصف meta فريدان + `canonical`
- Open Graph و Twitter cards + صورة OG مُبرندة
- **JSON-LD**: `EducationalOrganization` · `LocalBusiness` · `Service` · `FAQPage` · `BreadcrumbList`
- قسم أسئلة شائعة مرئي (٤ أسئلة) مطابق لما في الـ JSON-LD
- زر واتساب برسالة معبّأة مسبقًا تذكر المادة والمدينة + رابط `tel:`
- Breadcrumbs
- روابط داخلية: مواد شقيقة في نفس المدينة · نفس المادة في المدن الأخرى · نفس المادة في الأحياء · مواد ذات صلة
- شريط واتساب/اتصال ثابت أسفل الشاشة على الجوال

## قاعدة المحتوى (الأهم)

الصفحات شبه المكرّرة تُعاقَب من قوقل. لذلك في `data/catalog.ts`:

- لكل مادة **فقرة تعريف خاصة** ونقاط **«ماذا تفعل المعلمة»** مختلفة فعليًا
- لكل تقاطع (مدينة × مادة) حقلان خاصان: `cityAngle` (فقرة) و `cityFocus` (٣ نقاط)
- لكل منطقة `intro` متفرّد، ولكل حي `demand` (٣ نقاط عن طبيعة الطلب فيه تحديدًا)
- للأحياء المميّزة `subjectNotes`: فقرة خاصة بكل مادة أولوية **داخل ذلك الحي**
- أسئلة الأحياء وصفحات (حيّ × مادة) **تُشتقّ من `demand`** لا من قوالب عامة يتغيّر فيها الاسم
- أسئلة المادة **تُدوَّر حسب المدينة** فلا يتطابق قسم الأسئلة بين صفحتي نفس المادة

**عند إضافة مادة أو مدينة جديدة: اكتب لها محتوى جديدًا فعلًا، لا تنسخ محتوى مادة أخرى وتغيّر الاسم.**

القياس الحالي على المحتوى الأساسي (بدون الهيدر والفوتر ونصوص الروابط) عبر ١٢٣ صفحة:
متوسط التشابه **٩٫٨٪**، وأعلى زوج **٤٨٪**.

أعلى الأزواج هي **مادتان مختلفتان داخل الحي نفسه** (مثل `murwah/qudrat` مع `murwah/tahsili`)
لأنهما تتقاسمان وصف الحي — وهذا نمط مختلف عن «نفس المادة مكرّرة عبر عشرات الأحياء»
وهو النمط الذي يعاقبه قوقل فعلًا، وقد عولج بحقلي `subjectNotes` و`demand`.

لإعادة القياس بعد إضافة محتوى، انظر السكربت المذكور في قسم الفحص أدناه.

## نطاق Phase 1 (المُنجَز)

- **جدة كاملة**: صفحة المدينة + ٤ مناطق + ٣٦ حيًا + ٥٧ صفحة (حيّ مميّز × مادة أولوية) + ١١ مادة/برنامج
- **الرياض**: صفحة المدينة + ١١ مادة/برنامج (المناطق والأحياء في Phase 2)
- صفحتا **التأسيس الدولي** و**التخاطب وصعوبات التعلم** لكل مدينة (الأولوية)
- الرئيسية · تواصل معنا · صفحة ٤٠٤
- `sitemap.xml` · `robots.txt` · صورة OG · أيقونة

**المجموع: ١٢٣ صفحة ثابتة.**

## Phase 2 (لاحقًا)

- فتح مناطق الرياض: `published: true` في `data/catalog.ts` مع إضافة أحياء كل منطقة
- ترقية أحياء إلى `featured: true` عند الحاجة لصفحات مادة داخلها
- إضافة أحياء جدة الأصغر
- مدوّنة بسيطة لكلمات مفتاحية إضافية

## بعد النشر — خطوات يدوية

1. شراء الدومين وربطه بـ Vercel، وضبط `NEXT_PUBLIC_SITE_URL`.
2. **Google Search Console**: توثيق الموقع ورفع `sitemap.xml`. الترتيب لا يبدأ قبل زحف قوقل.
3. **Google Business Profile** (خرائط قوقل) — مهم جدًا لعمليات البحث المحلية «قريب مني».
4. مراجعة العميلة: اعتماد اسم البراند النهائي.

> توقّع واقعي: الموقع يُبنى في يوم، لكن **التصدّر يأخذ أسابيع** بعد النشر وزحف قوقل.
> الأسرع تحقيقًا: عبارات مثل «معلمة [مادة] في [حي/مدينة]» و«تأسيس انترناشونال جدة».

## قواعد البراند

- **التشكيل مقصود ولا يُحذف.** الاسم «مُدَرِّسة خصوصية» = المعلمة (الشخص).
  بلا تشكيل تُقرأ «مَدْرَسة» أي المبنى، وهو المعنى الخاطئ تمامًا لأن الخدمة
  معلمات خصوصيات لا منشأة تعليمية مرخّصة.
- **عبارات الاستهداف في H1 تستخدم «معلمة» لا «مُدَرِّسة»** — الزائر يبحث بلا تشكيل،
  و«مدرسة» بلا تشكيل تلتبس بالمبنى وتضعنا في منافسة مع المدارس بدل المعلمات.
  الاسم المشكول يظهر في اللوجو ولاحقة `<title>` والفوتر وصورة OG.
- كيان JSON-LD هو `LocalBusiness` لا `EducationalOrganization`، لأن الأخير
  يصرّح لقوقل بأننا مؤسسة تعليمية وهو ما لا ينطبق علينا.
- **لا تضع الاسم المشكول في نص معروض.** المتصفح يرسم الشدّة والكسرة على الراء
  كليجاتورة مكدّسة تضع الكسرة *فوق* الحرف فتُقرأ فتحة. للعرض استخدم
  `<BrandWordmark />`، وفي النثر وعناوين H1 استخدم **«معلمة»** فهي بلا تشكيل
  ولا تلتبس وهي عبارة البحث الفعلية. `BRAND.nameAr` مخصّص لـ`<title>`
  و Open Graph و JSON-LD حيث لا رسم يُساء.
- **اللوجو مسارات SVG لا نص.** `components/BrandWordmark.tsx` **مُولَّد آليًا ولا يُحرَّر يدويًا**
  (`npm run build && npm run wordmark`). السبب أن الشدّة والكسرة على الراء تتداخل أو تُزاح
  في بعض خطوط الأنظمة، والمسارات تظهر متطابقة على كل جهاز. النص المقروء يبقى متاحًا
  لقارئات الشاشة عبر `role="img"` و`aria-label` و`<title>`.
  التشكيل الصحيح: **كسرة + شدّة** على الراء (ليجاتورة `uniFC62`) — اسم فاعل «مُدَرِّسة».
  لو صارت فتحة (`uniFC60`) لانقلب المعنى إلى اسم مفعول «مُدَرَّسة» وهو خطأ.
- **الاسم يُطبع كما هو حرفيًا.** لا تشتقّ حرفًا من الاسم لتضعه بجانبه كعلامة —
  ذلك ينتج «م + مُدَرِّسة خصوصية» فيُقرأ «ممدرسة»، وهو الخطأ الذي ظهر سابقًا
  بصيغة «أأساس». علامة اللوجو رسم مستقل في `components/BrandMark.tsx`،
  ونفس الرسم في `scripts/generate-og.mjs`.
- تغيير الاسم يتم من `lib/config.ts` → `BRAND.nameAr` فقط، ثم `npm run build && npm run og`
  لإعادة توليد صورة OG والأيقونة بالاسم الجديد.
- الصياغة: **«نخبة من المعلمين والمعلمات المتميّزين»** — ولا تُستخدم كلمة «شبكة» في الموقع.

## مصطلحات ثابتة (لا تُخالَف)

| المصطلح المعتمد | لا تستخدم |
|---|---|
| **حضوري / حضورية** | منزلي / منزلية |
| **انترناشونال** | دولي / دولية |
| **نخبة من المعلمين والمعلمات المتميّزين** | شبكة |
| **معلمة** (في H1 والنثر) | مدرسة (بلا تشكيل) |

«انترناشونال» بالعربي هي عبارة البحث الفعلية عند أولياء الأمور، فاستخدامها
يحسّن الاستهداف. الـ slug يبقى `international` حتى لا تنكسر الروابط —
النص المرئي وحده هو ما تغيّر.

**ممنوع في نصوص الموقع:** أي جملة توحي بأن الحصة الأولى للتعارف أو لتقييم
المستوى، لأنها تُفهم على أنها حصة مجانية. حُذفت الفكرة من النص المرئي ومن
الـ FAQ في JSON-LD معًا (كلاهما يتولّد من المصدر نفسه).
